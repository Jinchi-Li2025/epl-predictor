# Changelog

## v1.0.0 - First public preview

### Added

- Premier League probability and scoreline dashboard
- XGBoost and Dixon-Coles production forecasting
- Chronological holdout and current-season validation
- Prediction ledger settlement and review dashboard
- Tactical-board lineup and complete match-squad views
- Player registry and squad-intelligence candidate features
- Guarded DeepSeek match and model explanations
- Calibration and squad-feature shadow challengers
- Operational readiness, contract, data-quality, and health checks

### Known limitations

- Current-season validation and settled squad history are still relatively small
- Some providers omit contract, valuation, lineup, or future-season fields
- Downloaded media and generated datasets are not distributed in the source repo
- Calibration changes remain shadow-only until uncertainty tests pass

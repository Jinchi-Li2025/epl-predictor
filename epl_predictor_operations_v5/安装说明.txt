EPL Predictor v5.0 运维自动化与影子校准升级
================================================

一、安装
--------

将解压后的 epl_predictor_operations_v5 文件夹放入：
C:\Users\Administrator\epl-predictor

在项目根目录、已激活(.venv)的PowerShell中运行：

powershell -ExecutionPolicy Bypass -File ".\epl_predictor_operations_v5\安装并检查.ps1"

完成后启动：

python -m streamlit run app.py

页面侧边栏将新增“系统运维”页面。


二、本次已经实现的内容
------------------------

1. 球员库质量审计
   - 当前FPL球队归属优先。
   - 检查同名球员的当前球队冲突。
   - 检查球衣号码、国籍、出生日期和FPL匹配覆盖率。
   - 只输出审计结果，不会自动改数据。

2. 数据契约门禁
   - 检查重复match_id、开球时间、主客队和上下文对齐。
   - 检查主胜/平/客胜概率是否在0到1之间且总和为1。
   - 错误与普通警告分开处理。

3. 概率校准Shadow Challenger
   - 只使用时间顺序切分，不随机打乱。
   - 在前70%数据选择temperature scaling参数。
   - 在后30%数据计算Log Loss、Brier和准确率。
   - 使用2000次成对bootstrap评估Log Loss改善置信区间。
   - 即使通过第一道门禁，也只会标记为“继续影子观察”。

4. 统一运维门禁
   - 合并系统健康、数据契约、球员库、LLM证据、模型监控和Challenger状态。
   - 区分“可继续展示现有预测”和“候选模型可否晋级”。

5. 比赛日近实时刷新
   - 默认只在开球前3.5小时至开球后15分钟内工作。
   - 刷新天气、裁判、伤停、首发/替补、新闻、DeepSeek解读、赛前简报和阵容快照。
   - 没有临近比赛时直接退出，不会进行远程请求。
   - 不重新训练生产模型。

6. 日更新流水线接入
   - 原有 run_daily_update.py 会自动追加球员库审计、概率校准影子实验、数据契约和运维门禁。
   - 手动运行原来的每日更新命令时，不需要另外记住v5检查命令。


三、常用命令
------------

执行全部运维检查：
python src\pipeline\run_operational_checks.py

检查是否进入比赛日刷新窗口：
python src\pipeline\run_matchday_refresh.py

立即强制测试一次比赛日流程：
python src\pipeline\run_matchday_refresh.py --force


四、可选Windows自动任务
---------------------

安装包默认不会修改Windows计划任务。
如确定希望自动运行，再手动执行：

powershell -ExecutionPolicy Bypass -File ".\scripts\install_v5_windows_tasks.ps1"

默认创建：
- 每天06:30运行完整日更新。
- 每15分钟检查是否有即将开球的比赛。
- 无比赛时，比赛日脚本不进行远程刷新。

删除这两个计划任务：

powershell -ExecutionPolicy Bypass -File ".\scripts\uninstall_v5_windows_tasks.ps1"


五、安全边界
------------

- 不自动修改生产概率。
- 不自动晋升任何Challenger。
- DeepSeek不能改写标签、比分、概率或模型权重。
- Windows计划任务只在用户另外执行安装命令后才会创建。

EPL Predictor 可靠性与监控升级 v4.0
====================================

安装（只需一条命令）
--------------------

把解压后的 epl_predictor_reliability_upgrade_v4 文件夹放进：
C:\Users\Administrator\epl-predictor

确认终端左侧显示(.venv)，然后在项目根目录运行：

powershell -ExecutionPolicy Bypass -File ".\epl_predictor_reliability_upgrade_v4\安装并构建.ps1"

完成后启动：

python -m streamlit run app.py


本次核心升级
------------

1. DeepSeek证据边界
   - 对摘要中的球员和球队进行本场归属校验。
   - 如果曼城vs富勒姆的文字混入其他球队球员，自动隐藏整段AI解读。
   - 页面回退到确定性的结构化摘要，冻结概率完全不变。
   - 记录公开新闻标题、链接、证据状态和被拦截实体。

2. 模型漂移与概率校准
   - 自动计算Log Loss、Brier、准确率与ECE校准误差。
   - 比较最近窗口和此前窗口的Log Loss。
   - 出现明显校准差距或近期恶化时给出警告，但不自动改模型。

3. 可下载赛前简报
   - 每场比赛页面增加“下载本场赛前简报”。
   - 简报包含冻结概率、最可能比分、结构化判断、证据状态和来源。
   - 被拦截的AI文字不会进入下载文件。

4. 模型中心
   - 新增“漂移与校准监控”。
   - 展示校准分箱、ECE、近期表现警告和DeepSeek证据审计。

5. 数据新鲜度
   - 健康检查不再只检查文件是否存在，也检查关键数据是否过期。
   - 不显示任何API密钥内容。


安装说明
--------

- 脚本会先备份被替换文件到 backups\reliability_v4_时间戳。
- PowerShell脚本保持纯ASCII内容，兼容Windows PowerShell 5.1。
- Streamlit使用python -m streamlit启动，避免streamlit.exe被系统策略拦截。
- 首次构建会运行证据校验、赛前简报、模型监控和健康检查。
- 样本不足时监控只显示“描述性结果”，不会误报模型已经失效。


以后每日更新
------------

继续运行原来的每日更新命令即可。v4步骤已经接入run_daily_update.py：
统一赛前报告 -> AI证据校验 -> 赛前简报 -> 阵容快照与Challenger ->
模型监控 -> 系统健康检查。


安全边界
--------

- DeepSeek不修改概率、权重或生产配置。
- 发现跨比赛实体时隐藏文字，不尝试用大模型“自行纠正事实”。
- 监控告警不会触发自动重训或自动晋升。
- 所有候选特征仍须经过时间顺序验证与人工复核。
